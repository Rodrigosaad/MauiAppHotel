# App Hotel (.NET MAUI)

Aplicativo desenvolvido para a **Agenda 13** do curso técnico em Desenvolvimento de Sistemas (Programação Mobile I) da **ETEC**[span_0](start_span)[span_0](end_span).

## 📱 Sobre o Projeto
O **App Hotel** é uma aplicação mobile multiplataforma construída com **.NET MAUI**[span_1](start_span)[span_1](end_span). O objetivo principal é explorar recursos avançados de interface gráfica, manipulação de componentes visuais e a comunicação entre o front-end em XAML e a regra de negócio em C# através do conceito de *Binding Context*[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).

## 🚀 Funcionalidades
- **Seleção de Suítes:** Escolha entre diferentes tipos de quartos (Luxo, Single, Casal, Família) com valores de diárias customizados.
- **Controle de Hóspedes:** Utilização de componentes *Stepper* para definir de forma incremental a quantidade de adultos e crianças[span_4](start_span)[span_4](end_span).
- **Agendamento de Estadia:** Seleção interativa de datas de Check-in e Check-out com validações via *DatePicker*[span_5](start_span)[span_5](end_span).
- **Cálculo Automático:** Processamento em tempo real do valor total da estadia com base no número de diárias e hóspedes[span_6](start_span)[span_6](end_span).
- **Tela "Sobre":** Seção dedicada com informações institucionais e autoria do projeto[span_7](start_span)[span_7](end_span).
